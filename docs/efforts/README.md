# Efforts

Briefs for off-arc work: defects, spin-offs, and cross-cutting fixes (jon-platform ADR-0005 D4). Milestone
slices don't get one; `NEXT_UP.md` points straight at the milestone.

**The root holds only live briefs; the location is the status** (ADR-0005 D10). Each opens with `Status:`
(**Designed**, **Ready**, **Dispatched**, **Blocked**) and a one-line `Summary:`. Finished and parked briefs
move to `archive/` with `jon-platform/scripts/archive-brief`. The order of the rows below is the queue
(D12).

Cockpit — Privacy Policy

Last updated: 11 September 2026

Cockpit is a personal application built and used by one person, Jon Phillips. It is not offered to the public, has no other users, and has no accounts to create. Questions: jon@jonphillips.com.

What Cockpit handles

  • Google account identity. The email address and basic profile returned by Google Sign-In, used only to identify which mailbox is connected.
  • Gmail content. Under the gmail.modify scope, Cockpit reads message content and metadata from the connected mailbox, and applies labels, archives, or trashes messages only at the user's direction. It never sends mail.
  • Web content. Articles and posts from the RSS and Atom feeds the user chooses to follow.

Where it is stored

Cockpit runs on the user's own Apple devices. There is no Cockpit server, no hosted ingest, and no developer-side database. Content is stored locally on the device and synchronized only through the user's own private Apple iCloud (CloudKit) container, which the developer has no access to.

Who else sees it

One exception to the above. Cockpit uses a large language model to select and summarize each day's reading. Text derived from feeds — and, where a mailbox is connected, from email messages — may be sent to a model provider's API (Anthropic and/or OpenAI) for that purpose, or handled entirely on-device where an on-device model is used. This happens only to produce results shown to the user. Cockpit sends that content under standard API terms, which do not grant the provider rights to train models on it. Nothing is sold, shared for advertising, or disclosed to anyone else, and no data is used to train any model by Cockpit or its developer.

Google user data

Cockpit's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is never used for advertising, never sold, and never used to develop, improve, or train generalized AI or machine learning models.

Retention, deletion, and revoking access

Content is kept until it is deleted. Access to the Google account can be revoked at any time at myaccount.google.com/permissions. Deleting the app and its iCloud container removes the stored copy.

Changes

If this policy changes, the date above changes with it.

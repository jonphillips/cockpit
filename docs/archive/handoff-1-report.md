# Handoff 1 report

`CockpitCore` now holds the first persistence spine: SQLiteData schema, deterministic UUIDv5 ContentPiece identity, RSS/Atom discovery and parsing, provenance-preserving Artifact ingestion, and a deliberately plain inspection-only iPad shell. The identity namespace is fixed in both code and contract as `4577b834-26f2-58c0-bed6-e73143426dff`; every device therefore derives the same ContentPiece primary key from the same canonical identity string.

Feed ingestion is transactionally idempotent. A repeat poll of one Stream retains the original Artifact rather than manufacturing more provenance rows, while the same item arriving through a second Stream creates its own Artifact and converges on the existing ContentPiece. Database migrations enforce that rule with partial unique indexes for `(streamID, providerID)` and the provider-less canonical-URL fallback. Later polls preserve existing judgment fields and readable text when the feed no longer supplies a body; they do not fabricate text from a title. Discovery or parsing failure marks the Stream failed and rethrows the original error. Parser coverage includes RSS, RDF, Atom authors, and named-zone dates.

The Gmail viability probe completed an iPad authorization using the configured iOS client and `gmail.modify`; it has not read, changed, or sent mail. The app now also includes the D7 non-interactive revalidation path: restore the Keychain-managed authorization, then refresh tokens if needed. D7 is not complete: the Google OAuth audience must first be published as unverified Production under the documented personal-use exemption, then this native check must be run on day 8. Publishing is a user-controlled Google Cloud action and has not been performed here.

D6 is explicitly guarded rather than silently violated. The current inline `ContentPiece.normalizedText` model cannot meet the contract’s “Library child record only” sync rule because Library membership/child records are out of this slice. `makeSyncEngine` therefore refuses to create a sync engine, with a test enforcing that boundary. The next persistence slice must introduce the contract-approved Library ownership shape before enabling CloudKit sync.

Verification: `swift test` passes 11 deterministic core tests. The iOS project was regenerated and passes an unsigned generic-device build. The current branch is `feat/spine`; no `feat` ref existed, so the earlier claim that this branch name was impossible was incorrect.
